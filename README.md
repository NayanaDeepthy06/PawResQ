# PawResQ

**PawResQ: AI-Powered Street Animal Injury and Welfare System**

PawResQ is a full-stack web platform that helps citizens report injured street animals, prioritize urgent rescue cases, and connect reports with nearby NGOs and verified volunteers.

## Problem

Street animals often suffer from accidents, injuries, hunger, and abandonment. Rescue requests are usually scattered across phone calls, social media, and messaging apps, making it difficult for animal welfare teams to track, prioritize, and respond to urgent cases.

## Solution

PawResQ provides a centralized rescue coordination system where users can submit animal injury reports with image, description, and location details. The system supports severity triage, priority scoring, NGO matching, emergency volunteer escalation, rescue tracking, and adoption support.

## Key Features

- Injured animal report submission
- Image upload support
- Injury description and location capture
- AI-assisted injury severity triage
- Priority scoring based on severity and distance
- Nearby NGO matching
- Emergency volunteer escalation
- Rescue status tracking
- Adoption support for rescued animals
- Admin and NGO dashboard support
